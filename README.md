# dio-virtual-machine-azure

Durante a atividade de criação de uma máquina virtual (VM) na plataforma Microsoft Azure, foi realizada a configuração de uma instância utilizando o sistema operacional Windows Server 2022. Embora o processo tenha sido concluído com sucesso, senti falta de uma abordagem mais completa em relação a aspectos recomendados pela própria Microsoft para uma boa prática de implantação em nuvem. Entre os pontos que poderiam ter sido melhor explorados estão: configuração de rede virtual, regras de segurança (NSG), armazenamento, organização por grupos de recursos, além do uso de tags e políticas de acesso para facilitar o gerenciamento e controle dos recursos. A inclusão desses tópicos teria contribuído para uma compreensão mais robusta e alinhada com os padrões profissionais de infraestrutura na Azure.
