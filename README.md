# dio-virtual-machine-azure

Durante a atividade de criação de uma máquina virtual (VM) na plataforma Microsoft Azure, foi realizada a configuração de uma instância baseada no sistema operacional Windows Server 2022. Apesar da proposta do curso indicar que seriam abordados tópicos fundamentais como configuração de rede virtual, regras de segurança (NSG), armazenamento, grupos de recursos, e boas práticas como uso de tags e políticas de acesso, infelizmente esses conteúdos não foram devidamente explorados ou ensinados com clareza. A experiência acabou sendo limitada à criação básica da VM, sem aprofundamento nos elementos essenciais para uma gestão eficiente e segura de recursos em nuvem. Essa lacuna comprometeu a compreensão completa do processo e da arquitetura envolvida na criação de ambientes virtuais na Azure.
